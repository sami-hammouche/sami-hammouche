## 💡 About me

I'm a third-year Computer Science student (Licence 3, **Systems & Networks** track) at Université Évry Paris-Saclay,
and I'm also following the **42 Paris** Common Core in parallel.

I like understanding what happens close to the machine: how a packet is routed from one network to another,
how memory is managed in C, how a Linux system is configured and secured from scratch.

I learn by building. I take a concept, implement it, break it, and rebuild it until it makes sense —
usually somewhere around the third attempt. When a tool I need doesn't exist, I write it
(that's how [exam42](https://github.com/sami-hammouche/exam42) was born).

**What I bring to a team**

- 🖧 **Networking & systems:** static routing on Debian, IP forwarding, packet analysis with Wireshark, SSH hardening with TOTP two-factor authentication (PAM)
- ⚙️ **Low-level programming:** C written under the strict 42 Norm, `-Wall -Wextra -Werror`, no standard library — every function rebuilt by hand
- 🧩 **Software projects:** Java (OOP, MVC, Swing), Python tools and GUIs, a Chrome extension in JavaScript
- 📝 **Clear documentation:** every project comes with a README that explains *what* was done and *why*
